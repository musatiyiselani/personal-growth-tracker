# Personal Growth Tracker

## About This Project

**ChatGPT:**

Personal Growth Tracker is a web application created by ChatGPT to give **Musa Tiyiselani Mathebula** a central place to track personal development, set goals, record achievements and monitor progress over time.

The initial application code was written by ChatGPT, not Musa.

The purpose of creating this application is twofold:

1. To provide Musa with a functional system for tracking personal growth.
2. To give Musa an opportunity to explore, understand and gradually learn Web Development through a real-world application.

The application will first serve its practical purpose. As Musa's programming knowledge improves, he can begin understanding its implementation, modifying features and eventually rebuilding the application independently.

## Why Are We Building It?

**ChatGPT:**

Musa has several ambitions and areas of development he would like to monitor.

Rather than keeping track of everything mentally, this application will provide a structured way to:

- Set and manage goals.
- Record daily activities.
- Monitor educational progress.
- Track Web Development learning.
- Monitor personal habits.
- Record achievements.
- Reflect on improvements.
- Review weekly and monthly progress.

The intention is to make personal development measurable and easier to manage.

## Technology Stack

The current build uses:

- HTML, CSS and JavaScript (frontend, hosted on GitHub Pages)
- Python with FastAPI (backend API, hosted on Render's free tier)
- PostgreSQL on Neon's free tier (all data, including profile pictures)

Source control and deployment: Git and GitHub.

To run the project on your computer, see `backend/README_SETUP.md`.
To deploy it on free hosting, see `DEPLOYMENT.md`.
